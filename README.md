## 🚀 Cómo Usar Este Repositorio

### Prerrequisitos

- Go instalado en tu sistema (versión 1.16 o superior)
- Editor de código (VS Code, GoLand, etc.)

### Ejecutar los Ejemplos

1. Navega a la carpeta del ejemplo que deseas ejecutar:
```bash
cd GO_S1_POO
```

2. Ejecuta el programa:
```bash
go run main.go
```

### Compilar un Programa

Para compilar un programa Go:
```bash
go build main.go
```

Esto generará un ejecutable que puedes correr directamente.
